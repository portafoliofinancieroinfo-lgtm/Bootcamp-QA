# 📋 Documentación de Pruebas Manuales

Esta sección reúne el trabajo de **QA manual** desarrollado durante el bootcamp:
diseño de pruebas, ejecución sobre aplicaciones web, móviles y APIs, y reporte
formal de defectos gestionados en **Jira**.

Cada subproyecto incluye su documentación en Markdown y la **evidencia original**
(hojas de cálculo, diagramas, capturas) en la carpeta `evidencia/`.
