## 🎯 Habilidades técnicas cubiertas

- **Automatización web**: Selenium WebDriver, esperas explícitas, patrón Page Object Model (POM).
- **Pruebas de API**: diseño de casos por partición de equivalencia y valores límite, validación de códigos de estado y mensajes de error con `requests` + `pytest`.
- **Reporte de bugs**: documentación de hallazgos con severidad, evidencia y recomendación (ver [proyecto final](./04-proyecto-final-urban-grocers-qa)).
- **Buenas prácticas de código**: separación de configuración, datos y lógica de prueba en cada suite.

## 🏆 Proyecto destacado

El [proyecto final de Urban Grocers](./04-proyecto-final-urban-grocers-qa) es el
que mejor resume mi forma de trabajar como QA: no solo automaticé los casos,
sino que **encontré y documenté defectos reales** (incluido un error 500 del
servidor) con un reporte claro de impacto y recomendaciones, tal como se
esperaría en un entorno de trabajo real.
